# Billy Martínez — Professional Portfolio

Portafolio bilingüe y pre-renderizado de Billy Martínez. Posicionado para roles de Solutions Engineering, consultoría técnica SAP y entrega full-stack.

## Desarrollo

```bash
npm install
npm run dev
```

## Verificación

```bash
npm run typecheck
npm run build
```

El build genera HTML completo para inglés, español y sus versiones plain; el contenido principal sigue siendo legible sin ejecutar JavaScript. El despliegue a `billyflin.dev` se realiza mediante GitHub Pages al publicar en `master`.
